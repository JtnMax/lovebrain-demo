## 📖 项目简介

**恋爱脑 LoveBrain** 是一款为情侣设计的温暖应用。这个 Demo 展示了完整的用户流程和核心功能，参考了多邻国(Duolingo)的游戏化设计理念，采用独特的 **Jelly Pop 弹性美学**，打造了一个充满趣味和温度的恋爱陪伴平台。

### 🎯 核心价值

- **关心信号系统** — 随时随地发送温暖的关心信号给另一半
- **恋爱历程记录** — 用时间轴记录每一个珍贵时刻
- **纪念日管理** — 永远不会忘记重要的日子
- **亲密互动** — 即时聊天、相册分享、愿望清单、日记记录
- **冷静期保护** — 结束关系时有 72 小时冷静期，保护用户权益

## ✨ 核心功能

### A. 用户认证与关系绑定
- **📱 登录注册** — 手机号验证码登录
- **🔗 关系绑定** — 邀请码 + 二维码扫描绑定另一半
- **⚙️ 首次引导** — 设置纪念日、生日、通知偏好

### B. 关心互动
- **💌 关心信号** — 8 种预设信号 + 自定义文本
- **💬 即时聊天** — 实时消息、图片分享、自动回复
- **🎁 愿望清单** — 记录彼此的小心愿，完成后打勾

### C. 记录与回忆
- **📅 纪念日管理** — 创建、编辑、倒计时提醒
- **📸 相册管理** — 分类相册（日常、旅行、美食、私密）
- **📔 恋爱日记** — 心情选择、富文本编辑、图片上传
- **📊 恋爱历程** — 时间轴展示所有重要事件，显示在一起天数

### D. 个人中心
- **👤 个人资料** — 用户信息、统计数据、关系状态
- **⚙️ 设置** — 通知、隐私、免打扰、语言、关于
- **🚪 结束关系** — 72 小时冷静期确认机制

## 🎨 设计理念

### Jelly Pop 弹性美学

这个 Demo 采用了独特的 **Jelly Pop 弹性美学**，灵感来自多邻国的游戏化设计：

#### 🎨 色彩系统
- **主色** — 蜜桃粉 `#FF6B8A` + 玫瑰金渐变 `#FECFEF`
- **辅色** — 薄荷绿 `#4ECDC4`、天空蓝 `#A8EDEA`
- **CTA** — 活力橙 `#FF6B35`、多邻国绿 `#58CC02`、向日葵黄 `#FFC800`

#### 🎭 吉祥物
心形吉祥物拥有 5 种表情：
- 😊 **Happy** — 欢快、积极
- 💕 **Love** — 温暖、甜蜜
- 🤔 **Thinking** — 思考、沉思
- 👋 **Waving** — 友好、问候
- 🎉 **Celebrate** — 庆祝、兴奋

#### 🔘 3D 果冻按钮
按钮具有立体感和弹性反馈，按下时会"压扁"并弹回，完全复刻多邻国的标志性交互。

#### ✨ 微交互
- 心形粒子动画
- 浮动吉祥物
- 庆祝动画
- 流畅的页面过渡
- 游戏化的进度条

## 🚀 快速开始

### 前置要求
- Node.js 22.13.0+
- pnpm 10.4.1+

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/JtnMax/lovebrain-demo.git
cd lovebrain-demo

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 预览生产构建
pnpm preview
```

开发服务器启动后，访问 `http://localhost:3000` 即可查看 Demo。
